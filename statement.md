# Project Statement

## Project Title

Student Management System using Python

## Problem Statement

Managing student information manually can be time-consuming and may result in errors, duplicate records, or difficulty in retrieving information.

The Student Management System provides a simple computerized solution for storing and managing student records.

The application allows users to add, view, search, update, and delete student information. It also supports marks entry and academic performance reporting.

## Scope of the Project

The project covers:

- Student record management
- Student searching
- Updating and deleting records
- Marks management
- Total and percentage calculation
- Grade calculation
- Pass/fail determination
- Student performance reports
- Local JSON-based data storage
- Input validation and error handling

The current version is a console-based Python application.

## Target Users

The intended users are:

- Teachers
- Faculty members
- Academic administrators
- Students for basic record viewing
- Beginners learning Python programming

## High-Level Features

1. Add student
2. View students
3. Search student
4. Update student
5. Delete student
6. Enter marks
7. Generate student performance report
8. Store records using JSON
9. Validate user input
10. Handle common errors
